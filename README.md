# Gospel Video Studio CTA

Static next-step pages for Gospel Video Studio videos, published with GitHub Pages.

Each page lives in its own directory. `turn-around/` contains the generated Turn Around page and its assets. The root `index.html` lists the available pages.

Publish changes by committing and pushing to `main`; GitHub Pages serves the repository root. Preserve each generated page's files exactly so Studio can compare the live page with its selected version.
